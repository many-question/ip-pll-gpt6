# VCO 修复候选 R2

本目录的推荐入口是 `lc_vco_repaired.scs` / `tx_lc_vco_repaired`。功能、频点、噪声和数值验证结果见 [验证说明](../../integration/vco_v4/README.md)。这是 PDK MOS/nmoscap 加暂定电感 RLC 的前仿电路，不是版图或工艺电感签核结果。

## 电路变更

| 部分 | R2 参数 / 实现 | 目的 |
|---|---|---|
| 交叉耦合核心 | 每管 W/L = 120 µm / 0.18 µm，NMOS | 增加低频端负电导；旧版为 40 µm |
| 两支电感 | 各 2 nH，Rs = 6.822430344 Ω；沿用 v3 pi 网络 | 保持在 3.3 GHz 拟合 Q = 5 的同一损耗假设 |
| 粗调电容 | 每侧 8 位二进制阵列，单位 4.4 fF | 去掉过多的低频调谐余量并减小寄生 |
| 粗调开关 | 单位 NMOS W/L = 1.2 µm / 0.18 µm，随位权放大 | 降低关断寄生；导通损耗保留在器件模型中 |
| 关断底板偏置 | 每位增加 W/L = 0.3 µm / 0.18 µm 的小 PMOS，同位控制 | 关断时拉向 VDD，避免浮置底板；导通时断开上拉 |
| 固定电容 | 每侧 10 fF | R1 的 20 fF 中部分改为可调电容 |
| 细调电容 | 每侧 PDK `nmoscap`，lr = 2 µm、wr = 4.5 µm、mr = 1 | 扩大粗调进位处的细调重叠；R1 的 wr = 3 µm |
| 主尾管 | W/L = 30 µm / 1 µm | 保留高频码的较低电流 |
| 分段尾管 | b3…b7 控制 0.5、1、2、4、8 µm / 1 µm 的镜像支路 | 低频码逐步增加电流，避免单一大电流台阶 |
| 支路使能 | 每支尾管源端串联 NMOS，W 为该尾管的 4 倍，L = 0.18 µm | 尾管栅始终接同一滤波偏置，减小粗调对偏置滤波器的充放电影响 |
| 偏置 | IREF = 80 µA；基准镜像管 2 µm / 1 µm；1 MΩ / 10 pF 滤波 | 电流基准发生器按人类约定继续后置 |

尾电流的名义设计关系为：

`I_tail ≈ 80 µA × [30 + 0.5 × floor(code / 8)] / 2`。

这是尺寸比的解释，忽略沟道调制和使能管压降。实际电流、功耗均从 Spectre 支路电流积分取得。位码增加时电容和电流同时增加；不能沿用旧版 VCO 的频率表、Kvco 或系统鉴相增益。

## 接口与依赖

```spectre
// 加载 PDK 对应 MOS、stat_noise 和 bbmvar 角后：
include "lc_vco_repaired.scs"
XV (vp vn ctrl b0 b1 b2 b3 b4 b5 b6 b7 vdd vss) tx_lc_vco_repaired
```

粗调位为 0 / 1.2 V，b0 是最低位。验证的细调电压范围为 0.2–1.0 V；电源 1.2 V。输出是差分谐振波形，不是全摆幅 CMOS GHz 时钟。

需要 `lc_core_v4r.scs`、`cap_bank_switched_v4.scs`，以及 [v3 的 inductor_pi.scs](../transistor_v3/inductor_pi.scs)。验证脚本会递归收集并上传这些依赖。公开入口默认参数另有独立 smoke test，与显式参数实例比对，避免只验证 TB 覆盖值而交付错误默认值。

`lc_vco_v4n/c/b/d/s/r.scs` 是保留的实验入口。特别是其默认参数服务于早期筛选，不应代替上述公开入口；每次历史运行的完整输入快照都保存在本项目 `research/runs/spectre_vco_v4/`。

## 边界

- 电感仍是人类允许的初步 RLC 模型。Q、寄生、温度系数、几何、互感及基底耦合未得到 PDK/EM 保证。
- 固定/粗调电容仍是理想电容加真实 MOS 开关；实际工艺电容、布线、栅电阻与多指版图寄生尚未提取。
- 核心与尾管、开关、底板偏置均是实际 PDK MOS；IREF 发生器仍理想。没有新增理想负电阻或行为振荡源。
- 起振验证从已经建立的 DC 偏置和 10 µV 差分种子开始；真实电源爬升、基准发生器和偏置滤波器冷启动仍待实现后验证。
- 全频点加载验证中的分频器、采样器、CP、参考缓冲和脉冲电路是真实器件；CP 输出被钳位，VCO 控制电压由 TB 设置。这不等于完整 PLL 捕获或锁定。
- 需重新标定实际采样摆幅、Kpd、Kvco 和环路参数，再代回 FLL/PLL；尚不能据此宣布 <200 fs、≤4 mW 或 <0.3 mm² 达标。
