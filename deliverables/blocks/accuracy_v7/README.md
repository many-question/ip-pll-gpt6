# 关断分频支路删减诊断

`divider_active4_diagnostic.scs` 只保留 closure_v6 钳位版的 ÷4 支路及公共输入/偏置/输出。删去了未启用的 ÷6…÷14 支路，保留原端口列表以便复用测试台。

这不是六档分频器候选电路，不能代回完整系统交付。删减同时改变高阻状态的数量和 VCO 所见负载；即使周期求解改善，也不能唯一归因于高阻状态。本试验用来检查“去掉未启用支路是否足以恢复闭环周期求解”这一假设。

物理状态由前轮钳位版 1 ps、4 µs 的终态派生，仅移除观察器和不存在的分支状态。来源、删除项及哈希见 [诊断协议](../../integration/accuracy_v7/results/inactive_bank_ablation.json)。完整六档电路仍以 [closure_v6](../closure_v6/README.md) 为研究候选。

本轮长时间接续与步长对照均使用完整六档电路，没有应用这一删减。
