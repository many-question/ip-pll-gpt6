# 关断分频支路偏置钳位候选

`divider_bank_v6_clamp.scs` 从已交付的 `interface_v5/divider_bank_v5.scs` 派生。VCO R2、采样电阻与滤波器均不在此文件中修改。

每个分频分支的两个输入选择传输门与 500 fF 耦合电容之间，增加一个连接至 `cim` 的互补传输门。其控制与输入选择相反：分支关闭时，耦合电容前端被钳至输入共模；分支启用时，钳位关闭。每个新增传输门使用 NMOS W=0.5 µm、PMOS W=1 µm、L=0.18 µm，六个分支共新增 12 个传输门、24 个 MOS。

原电路这些节点只能通过关断 MOS 的漏电获得直流状态。DC 对照显示其工作点对仿真器辅助电导敏感；这是增加实际偏置路径的动机，不把理想电阻或额外 gmin 当成最终电路。

候选仍需完整加载、PVT、噪声、动态选择及面积验证。未替换原接口或继承原 VCO 的 99 点覆盖证据。所用 10 kΩ 采样偏置、10 pF 去耦组合仍是上一轮的研究候选，暂不作为降噪推荐。测试及证据见 [闭环研究](../../integration/closure_v6/README.md)。
