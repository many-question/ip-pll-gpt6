# output_v9：差分 CML 重定时试验电路

本轮电路使用 TSMC180 BCD Gen2 MOS，继续研究实际 VCO 形状时钟下的输出噪声。属于未冻结的研究候选；验证结论见 [集成记录](../../integration/output_v9/README.md)。

- `divider_raw_v9.scs`：从 v6 六档钳位分频器导出真实差分数据；去除原单端 CMOS 恢复链，并给负端增加同尺寸选择传输门。六档实体电路仍存在，本轮只测试 /4。改变了数据与 RF 加载，旧码表/PVT 不自动继承。
- `cml_retimer1_v9.scs`、`cml_retimer2_v9.scs`：复用项目 CML 锁存器，分别单锁存器与主从两锁存器。时钟通过 300 fF 耦合、电阻偏置及 10 pF 去耦；默认 30 µA 参考电流经实际 MOS 电流镜偏置。数据/时钟/保持晶体管、电阻负载以及输出四级自偏置链均计入器件噪声。
- `cml_retimer_regen_v9.scs`：两级 CML 后用项目既有差分再生接收电路在 984 MHz 恢复 CMOS 电平；互补输出同接 10 fF，以保持该试验的对称负载。发生器仍理想，接收电路内电流镜/MOS/电阻噪声正常打开。
- `limiter4_v9.scs`：将旧四级自偏置链的反馈电阻和耦合电容参数化，用于检查反馈电阻对摆幅的影响；低阻失败不能证明噪声改善。
- `data_wave_*_v9.va`：仅用于时序诊断的理想数据回放源，依据本轮真实分频器的稳态波形拟合。不是晶体管替代物，不出现在正式器件噪声 TB 中。

`scale` 同时缩放 CML 器件、电流及反比负载电阻；`lscale` 调输出反相器宽度。反相时钟试案只在 TB 对调 `cp/cn`，不含理想延迟线。具体尺寸和端口以各 TB 与运行时不可变输入快照为准。

电阻/电容仍为理想集中器件（电阻热噪声开启），RF 为理想无噪声电压源回放，偏置基准发生器后置。实际 VCO 阻抗/噪声回注、完整 PLL、PVT、失配、布局及寄生均不在本轮夹具中。
