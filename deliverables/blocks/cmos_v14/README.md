# CMOS v14：SS功能修复候选与试案

候选尚未冻结。实际LC验证结果及条件见 [集成说明](../../integration/cmos_v14/README.md)。只有存在对应通过记录的组合具备该条件下的功能证据；目录中的其他网表是诊断或失败试案。

| 作用 | 较轻候选文件 | 关键参数 |
|---|---|---|
| RF接收 | `rf_light24s12_v14.scs` | WN24/WP60 µm，L180 nm，C4 pF，反馈R20 kΩ |
| 首级TSPC反馈 | `ff_fbdelay50_v14.scs` | MN0门极串50 kΩ，PMOS反馈保持直接连接 |
| 固定÷4 | `div_fb50buf24_v14.scs` | 首级以上FF；级间缓冲0.8/0.5、2/4 µm；次级沿用原9T |
| 重定时及输出 | `rt_light24s12_out083_v14.scs` | v13 FF scale1.2；首缓冲3/0.5 µm、末缓冲0.8/3 µm |

主修复对照使用v13 `rf_cc4_v13`、同一新分频器与 `rt_rskew42_v14`（FF scale2，缓冲4/2及2/3.9 µm），实际LC SS200 µA通过但4.8872 mW。较轻候选在SS180 µA为4.3946 mW；尺寸减小降低RF负载，码24用于补偿频率变化，不能直接沿用码21表。

依赖的 `cells.scs`、`rtcomb_v13.scs`、实际VCO、参考、采样与CP文件均由TB显式include，运行器递归解析项目内依赖并冻结输入。50 kΩ目前是理想电阻+MOS门电容形成的延迟，没有伪造行为延迟器；但PDK电阻、容差、PEX及热噪声尚未验收。没有实现新的通用六档分频库、复位/保持或完整控制。

器件均使用获授权的TSMC180BCDGen2 MOS。三个小宽度失败试案低于模型220 nm限制，留存仅供审计，不能使用。其他宽度合法不代表时序或可靠性通过。所有试案状态以集成目录 `results/validation.json` 为准。
