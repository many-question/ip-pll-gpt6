# V14 指标与模块完成情况

更新：2026-10-04。按用户最新指示继续优先解决噪声和抖动；功耗只记录，优化暂缓，原指标保持。完整 `pll_capture_v14` 主电路尚未采用独立候选。

**局部输出链基线／2倍／4倍暂定RMS为141.281／90.867／63.275 fs，完整PLL仍未知。** TT27、1.2 V、984 MHz／10 fF、外部无噪声RF重放；10 kHz–492 MHz。2倍／4倍自身六点数值精度及六输出沿三点检查通过，2倍FF／缓冲／RX／分频及4倍FF／缓冲独立noise-on通过，其余逐组验证继续；MOS readpss噪声存在冲突，只采用fresh PSS。详见[噪声进展](NOISE_PROGRESS.md)。

真实LC诊断核心的两个250 ns初始化窗口发现约**−28.8 dBc参考杂散**，调制已在VCO端出现。暂定机制为采样负载切换，固定控制首例已保留99.3%的输出参考PM幅度，直接耦合得到证据；DC保持／跟踪频差9.531425 MHz已测得，KVCO继续、互补MOS补偿三例等待释放槽位；这是确定性调制，不能误计为随机抖动，也不是完整PLL最终杂散值。见[参考负载诊断](REFERENCE_LOADING_DIAGNOSIS.md)。

VCO CF10→40 pF候选已在相近工作点改善10 k／100 k／1 MHz相噪6.679／7.442／0.865 dB；尾管长沟道对照同时改变工作点、低频变差，未采用。实际LC四组短时加载比较已开始，基线3 µs／1 ps通过，输出983.999994 MHz、相位漂移−8.18e-5 rad/µs。RT4已完成但从相同初态滑相，输出986.004435 MHz、RF约3944.018 MHz，分频比例正确；不直接采用，先测加载曲线并重调交接。CF40实际LC近锁定3µs完成0error，末窗输出983.999339MHz、相位峰峰0.015177rad、漂移−0.015315rad/µs；漂移超出0.01rad/µs门限，稳态筛选未通过。需要延长稳定过程后再测噪声，不能判作没有锁定解；RT4+CF40仍运行。不作随机噪声、最终偏置稳定或冷上电验收。

修正供电初始化和进一步收紧itres均未解决所观察核心PSS发散，已停止、回收并审计；没有有效闭环PNoise。新的更稳定基线终态已准备仅改变初态的PSS对照，尚未运行；完整内部状态检查仍发现部分逻辑栈变化，详见[状态诊断](CORE_STATE_DIAGNOSIS.md)。完整PLL严格64 µs复位继续，尚未完成，未判通过。

连续时钟分频候选新增批次17/17通过；结合此前结果，11个不同SS规划端点、六档TT高RF和六档FF高RF接口通过。见[接口覆盖](results/bank_pulsetrip_coverage.json)。这是固定SS形状重放加实际MOS接收器的端口测试，未覆盖实际LC全频点、模式切换或完整PLL。

**电路实现已补齐，整机功能与性能尚未全面验收。** 当前 `pll_capture_v14` 的14个功能块都已有MOS／无源电路并接入顶层；项目层展开17,644 MOS、2个PDK变容、41 R、39 C、2 L及3个零伏电流探针。内部没有功能VA或理想电流基准。电感仍采用用户允许的暂定Q5 π型RLC，R/C尚未落实为经过版图提取的工艺无源器件；因此“电路已实现”不等于版图或工艺寄生已完成。

当前完整修复版的已完成复位结果只有 **TT27、1.2V、24MHz、K41/M4、984MHz输出、10fF、Q5 RLC** 这一点，使用maxstep=4ps、reltol=1e-4。下面“新整机”均指该条件。前一完整版本 `pll_complete_v14` 的严格近锁定、模块噪声等结果保留各自边界。
