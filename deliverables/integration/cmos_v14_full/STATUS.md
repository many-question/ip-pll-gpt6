# V14 指标与模块完成情况

更新：2026-10-04；按用户决定优先噪声与抖动，暂缓功耗优化，≤4mW目标保留。严格复位仍未完成；噪声恢复和局部尺寸实验见本节。本页区分当前修复版、修复前基线和独立模块结果，不把运行中的轨迹计为通过。


新增进展：完成37个SS时序诊断/修复短仿真，找到未使用尾级的数据负载及预分频输出驱动问题。独立候选`bank_preboost50_v14`在SS60的÷6/10/14已同时通过；理想20ps RF下六档×三配对角18例全部通过；接入实际MOS RF接收器后SS仅÷8/12/14通过，÷4/6/10失败，尚未代回完整PLL。详见[SS时序修复](SS_TIMING.md)。 本轮进一步采用实测SS RF形状并延长稳定时间：原版÷4通过；加倍动态输出候选q1仅约0.77V，后级停振；恢复原动态级后÷4通过，÷6/÷10仍有门控脉冲传播问题。新渐进驱动及P/N对照共九例未关闭问题，最后÷6约460.7MHz，仍未代回。

按用户要求同步启动[闭环器件噪声验证](NOISE_PROGRESS.md)：保留真实模拟反馈及快速输出链，先固定慢控制测量锁定核心，再补完整逻辑影响。稳定段仍滑相，PSS已停止；参考负载裁剪使边沿由约200/182ps变为60/53ps，已完成负载对照和物理粗调DFF恢复；2µs核心仍未稳态，后续5µs严格稳定段已通过，新的4MHz PSS于10月3日晚收敛失败，PNoise未执行；文本初态重启再次产生相位扰动，异常Newton迭代使内部节点越轨。现已保留失败证据，以同电路2µs稳定段/Gear2重新诊断；局部重定时/输出2倍尺寸已进入PNoise，4倍候选排队。当前没有新增RMS结果，不把核心近似当作整机验收。

**电路实现已补齐，整机功能与性能尚未全面验收。** 当前 `pll_capture_v14` 的14个功能块都已有MOS／无源电路并接入顶层；项目层展开17,644 MOS、2个PDK变容、41 R、39 C、2 L及3个零伏电流探针。内部没有功能VA或理想电流基准。电感仍采用用户允许的暂定Q5 π型RLC，R/C尚未落实为经过版图提取的工艺无源器件；因此“电路已实现”不等于版图或工艺寄生已完成。

当前完整修复版的已完成复位结果只有 **TT27、1.2V、24MHz、K41/M4、984MHz输出、10fF、Q5 RLC** 这一点，使用maxstep=4ps、reltol=1e-4。下面“新整机”均指该条件。前一完整版本 `pll_complete_v14` 的严格近锁定、模块噪声等结果保留各自边界。
