# RT4版图前剩余工作

更新：2026-10-12T17:23:17+08:00。按[DEC-0010](../../../reports/decisions/DEC-0010.md)，RT4已是后续开发主方案；选定电路与尺寸见[基线清单](results/rt4_adopted_baseline.json)。当前TT27/984MHz独立复位捕获与稳态器件噪声已有证据，最差高偏移RMS为115.2fs，用户接受作为继续开发的阶段结果。积分方法和种子小偏差不再扩展验证。

| 优先项 | 当前依据及缺口 | 版图前要得到的结果 |
|---|---|---|
| 1. 全频率功能与调谐范围 | 整环主要覆盖TT/984MHz；当前VCO电容单元仍4.4fF。旧同族LC端点约2.73–2.76GHz，高于规划低端2.688GHz；4.8fF独立候选有三角RF端点覆盖，但尚未并入RT4。 | 先处理2.688GHz低端覆盖，核验电容码连续性、粗细调重叠；完成216–984MHz共33点及六种分频比的TT功能，再用端点、分频边界和最差点检查角落。 |
| 2. 启动、切频与恢复 | RT4有供电预先建立后的复位捕获；尚非真实上电。 | 验证电源爬升、复位/配置时序、跨分频档切频、失锁重捕获及参考丢失/恢复；不能只用近锁定初态。 |
| 3. 工艺、电压、温度与关键失配 | 已有模块TT27/SS60/FF0，完整RT4缺系统覆盖。电压扫描边界未定义。 | 先筛慢热/快冷及混合角的RF接收、分频、采样时序和有效性检测，再对关键偏置/鉴相/判定路径做有限失配检查；按发现的薄弱点扩展，避免无目标的大矩阵。 |
| 4. 剩余前端性能 | 115.2fs只覆盖5.285–492MHz；完整RT4杂散未知，历史原版局部核心约−28.8dBc提示风险。 | 补10kHz至fOUT/2全带抖动以及完整RT4参考/整数杂散测量。保留已有最差值，不追加仅为抹平小数值差异的对照；局部杂散值不能直接归给RT4。 |
| 5. 工艺无源和实际接口 | Q5 RLC为允许的临时电感模型，部分R/C仍为理想数值；参考源阻抗/边沿和实际输出负载未定。 | 选定可实现的电感、开关电容、滤波R/C及偏置实现；确认参考输入、输出负载、配置引脚、电源域和允许的器件端电压；替换模型后回归关键工作点。 |
| 6. 功耗及版图交付包 | RT4复位测试末1µs总功耗8.050093mW，目标≤4mW；面积目标<0.3mm²，尚无物理估算。 | 前端工作后安排功耗分解与优化，尺寸确定后回归关键性能；形成选定网表/原理图、器件尺寸/无源参数、引脚表、匹配对称/隔离/关键寄生约束和初步面积预算。功耗及后端目前仍按此前安排暂缓。 |

建议执行顺序：**调谐范围及全频点功能 → 关键角落与启动/切频 → 全带噪声与整环杂散 → 工艺无源/接口及功耗定型 → 版图交付包**。可并行整理引脚和布局约束；最终尺寸依赖功耗与实际无源回归。DRC、LVS、PEX和后仿真在版图产生后完成，不列为开始版图之前必须已有的结果。

当前选择RT4不等同于所有REQ已通过。占空比沿用用户“无需刻意优化”的安排；33点、PVT、真实输入/负载、全带抖动、杂散、4mW功耗及面积缺口继续保留。此清单是接下来要做的工作，不是已完成记录。
