# 第115次：交接边界核查与单窗口物理诊断

现有证据尚不足以把粗码8在0.84V处的0.381MHz条件上端余量直接解释为FLL交接余量。本次核对了DAC、粗码位和复测预算，保持callback110完整网表、几何和控制器不变，安排一个7µs局部诊断。发布时该任务仍在运行，尚无终态或新性能结果。

## 已确认的逻辑与算术

- 原DAC为6位R-2R。忽略MOS驱动压降和负载时，输出为`1.2V × code / 64`；合法端点11/53约为0.20625/0.99375V。0.84V对应理想码44.8，实际高端粗码修正门槛49对应约0.91875V。实际电压仍需物理仿真，不能把理想关系当成实测。
- `recenter109`在复测模式下，DAC≤15且计数偏高请求粗码+1；DAC≥49且计数偏低请求粗码−1。此判断在±1计数合格判断之前，因此边缘处误差为−1或+1也可能先请求粗码修正。最多一次、不回绕；重新设DAC32及11..53搜索区间、清除旧合格标志，共用八次预算。
- 实测9→8只改变b0；8→7改变b0、b1、b2、b3，其中b3还控制5µm尾管和20µm使能管。因此不能用9→8的约7MHz变化预测8→7的实际变化。
- 128参考周期为5.333333µs，RF÷4计数的一计数折合RF0.75MHz。上次粗码8/0.84V最差100ns子窗余量0.380658MHz小于此量，但该比较既不是实际计数结果，也不证明误交接。
- 如果第3次复测才触发粗码修正，只剩5次。以“频率单调、仅一个内部DAC码恰好合格”的抽象比较为例，目标40的路径32→43→37→40→40可用5次，目标42的路径32→43→37→40→41→42→42需要7次。真实误差≤1可能对应更宽的合格区间；这只是说明现有预算不保证覆盖每一种情况，并非观察到了callback版捕获失败。预算保持不变。
