# CP 瞬态端口电流的独立核对

2026-10-04。本诊断保持 TT27、1.2 V、24 MHz 参考、3.936 GHz 理想 RF 波形回放、控制电压钳位和原 CP 尺寸。它解决测量依据问题，不给出整环抖动或器件内部实现的结论。

## 已观察到的差异

原始直接保存 MOS 端口电流的 [端口核对](results/cp_terminal_balance_validation.json) 中，尾节点和镜像节点通过预设的 `1e-3` 平均绝对 KCL 残差门限；尾管栅极节点残差为 `0.03742649`，未通过。该失败结果保留。

在三个支路串入零伏电压源后，[独立支路核对](results/cp_gate_branch_validation.json) 得到：

| 量 | 实际结果 |
|---|---:|
| 栅极节点支路 KCL 归一化残差 | 9.4933e-17 |
| 三个探针两端最大电压 | 0 V |
| 19 个保存电压的最大变化 | 1.5757e-12 V |
| 控制钳位平均电流变化 | −2.9065e-18 A |
| 传输门报告端口电流与独立支路的平均绝对差/两者绝对值之和 | 2.2319% |
| 关断管对应差异 | 4.7166% |
| 尾管栅极对应差异 | 2.5328e-9 |

传输门和关断管的保存端口量与独立支路测量不一致；尾管栅极量相符。所保存的这些信号类型均为电流，网表端口顺序已核对。尚未查明 Spectre/BSIM4 内部造成差异的具体原因，不能将上述百分数作为修正系数套用到其他器件。

## 当前使用方法

后续 CP 工作过程比较使用已经核验的三个独立支路计算栅极节点 KCL，保留原 MOS 端口量供诊断。符号由实际源端连接决定，不通过翻转符号或放宽门限拟合结果。新的电路候选仍需验证自身的周期状态、工作点及测量量。

本机已经保存的 Spectre 21.1 帮助文档说明：普通元件电流可以直接从器件输出取得，也可以通过 `useprobes` 选择插入电流探针；端口电流的正方向指向元件内部。此次采用明确的零伏支路，便于核对每条连接。文档也提示探针可影响数值求解，因此本实验实际比较了探针压降、平均控制电流以及保存的电压波形。

本地文档依据为 `research/spectre_help/options_noise_v10.txt` 的 `useprobes` 说明和注意事项，以及 `research/spectre_help/save_jitter_v11.txt` 的端口电流符号说明。未将整份工具文档纳入交付。

## 结论的边界

- 这是特定夹具中的端口报告不一致，不能推广为所有 MOS 保存量或所有 PNoise 输出均失效。
- 原先 95% 的输入对管导电电荷发生在使能窗外，来自分别保存的电阻性漏电流；它不是窗外噪声比例。器件电阻性电流、含位移的端口电流和独立支路电流始终分开记录。
- 测量修复没有证明短尾管或提高采样偏置一定更优。最终比较依赖实际平衡点、鉴相增益以及输出噪声；这些输出电流由独立控制钳位电压源测量。
- 原始输入和 PSF 在本项目 `research/runs/spectre_cmos_v14_full/cpterminalbalance01/` 与 `cpgatebranch01/`，对应结果文件记录 SHA-256，可重查。
