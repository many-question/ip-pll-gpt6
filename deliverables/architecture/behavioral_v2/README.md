# Python 完整捕获模型 v2

本轮在 v1 候选 B 上补充有限边沿计数 FLL、等电容粗调、滤波器预充交接、正确谐波判定和失锁重捕获。v1 的随机噪声结果与其限制保留；本轮新增的是确定性功能验证，不改变抖动积分口径。

运行入口（项目根目录）：

```powershell
python share/deliverables/architecture/behavioral_v2/run.py --out research/runs/behavioral_v2/new_run
```

`new_run` 必须不存在。需要 numpy、scipy、matplotlib；共用 `behavioral_v1/model.py` 与候选 B 配置。接受结果来自 `research/runs/behavioral_v2/run04`，交付副本位于 `results/`。

算法与条件：

- 24 MHz 参考，32 周期测频窗口，频率量化步长 0.75 MHz；使用实际累计振荡周期的整数差，不把目标频率写入振荡器。
- 256 个等电容粗调码，中心频率 `4 GHz / sqrt(1 + code/255*((4/2.64)^2-1))`；正 Kvco=20 MHz/V，控制中心 0.6 V、工作区间 0.2–1.0 V。
- 二分搜索只读取量化测频误差，保存最优实测码。每次换码后等待 2 个参考周期。确定粗调码后用实测剩余误差预置两只滤波电容，再交给正弦亚采样鉴相主环；不重置 VCO 相位。
- 主环采用 v1 的精确分段矩形脉冲状态转移：Kpd=2.4 µA/rad，脉宽及延迟各为 0.05 个参考周期，R≈22.222 kΩ，C1≈28.648 pF，C2≈1.910 pF。
- 交接后每 256 周期打开一个 32 周期的测频窗口，偏差超过 3 MHz 则重新捕获。这是行为控制策略，不是高速电路功耗实现或证明。
- 稳定判据：正确目标频率偏差 <1 kHz、相位误差 <0.01 rad，并在尾部至少保持 100 周期。任何采样内控制电压越界都使该案例不被接受。越界轨迹不用于推断实际限幅恢复行为。

观察结果：396 个名义启动情景（33 点 × 3 个初始码 × 4 个初相位）通过，最慢约 16.38 µs，控制电压采样范围约 0.327–0.851 V。66 个粗调频率整体 ±1% 的灵敏度情景通过；这不是 PVT 验证。注入 −24 MHz 扰动后看门狗触发重捕获并返回正确目标。与 VA 事件顺序核对后，将 Python 的选码和预充电压更新放在同一参考沿；run03 的一周期预充延迟已在 run04 修正，未改变通过结论。

保留的负结果：最初采用 2.66–3.96 GHz 保护范围时，−1% 情景无法覆盖 3.936 GHz，见 `research/runs/behavioral_v2/run01/summary.json`。因此提出 2.64–4.00 GHz 名义粗调保护范围；最大相邻码差约 10.124 MHz。**该保护范围是待工艺验证的工作假设，输出需求和已确认 VCO 使用频段不变，也不是团队冻结决定。** 即使调整后，+3% 情景的最低频点仍无法覆盖；模型检出失败而非接受附近错误谐波。

局限：预充在 Python 中理想化，控制范围外仅标记失败；未包含电容失配、非单调码、实际计数器亚稳态、器件 PVT、供电耦合与随机捕获噪声。完整同步边沿周期平稳噪声仍是 v1 已记录的缺口。本模型不是 RTL 或晶体管实现。
